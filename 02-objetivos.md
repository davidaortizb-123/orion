# 1.2 Objetivos — ORIÓN

## Objetivo general
Diseñar e implementar un sistema web para gestionar y controlar personal logístico por empresa, evento, sector y función, centralizando información personal y documental, controlando acreditaciones y registrando costos operativos.

## Objetivos específicos
- Registrar empresas y producciones.
- Asociar cada persona con empresa, evento, sector y función.
- Registrar y revisar documentos y vencimientos.
- Aprobar personal y generar una acreditación identificable.
- Registrar costos asociados a una producción y, cuando aplique, a persona, empresa o sector.
- Mostrar indicadores básicos en un dashboard.
- Validar los flujos con pruebas funcionales.
